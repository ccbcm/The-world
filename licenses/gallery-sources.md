# 壁纸与界面来源

- Vanta 0.5.24 — https://github.com/tengbao/vanta — Teng Bao — MIT，完整许可见 vanta.txt。收录 Waves、Clouds、Net，使用原 JS 代码，调整配色与速度，中文展示名由本站添加。封面为这些效果的截图。开源收录不代表作者入驻或背书。
- Catppuccin Wallpapers — https://github.com/daylinmorgan/catppuccin-wallpapers — Daylin Morgan — MIT，完整许可见 daylin-wallpapers.txt。收录 src/{cat,lines,caffeine,tux}/base.svg，保持原文件。
- Three.js r134 — Vanta 仓库自带依赖，MIT 许可声明保留在文件中。
- daisyUI — https://github.com/saadeghi/daisyui — MIT。仅研究圆角组件与内容层次，没有复制组件代码；本站以原生 HTML/CSS/JS 实现。
- 陆家嘴场景为 CCBCM 工程，场景素材独立许可见 素材来源.md。

动态效果是网页壁纸示例，不能冒充 MP4 下载。静态壁纸可直接下载 SVG。收藏只保存在本地浏览器。多人账号和投稿尚未接入。
